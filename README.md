# 🛒 쇼핑몰 고객센터 챗봇

쇼핑몰 고객 문의(배송, 환불, 상품 불량, 기타 문의)를 분류해서 알맞은 답변을 보여주는 Streamlit 챗봇입니다.
미리 모아 둔 예시 문장을 기준으로 질문을 분류하며, 외부 AI API는 사용하지 않습니다.

**배포 주소:** https://shop-chatbotgit.streamlit.app

## 주요 기능

- **세부 질문별 답변**: 같은 배송 문의라도 "언제 와요?", "조회 방법", "주소 변경"처럼 질문 내용에 따라 다른 답변을 보여줍니다.
- **카테고리별 예측확률**: 답변 아래에 카테고리 4개의 확률을 막대로 보여줍니다.
- **정확도 테스트**: 학습에 쓰지 않은 테스트 문장으로 카테고리 정확도와 세부 질문 정확도를 측정해 보여줍니다.
- **엑셀 저장**: 상담 기록과 테스트 분류 결과를 `.xlsx` 파일로 내려받을 수 있습니다.
- **이해 못한 질문 처리**: 어떤 예시 문장과도 충분히 비슷하지 않은 질문에는 고객센터 연락처를 안내합니다.

## 답변 범위

| 카테고리 | 세부 질문 |
|---|---|
| 배송 | 배송 기간, 배송 조회, 배송지 변경, 배송비, 도서산간 배송, 배송 지연·분실 |
| 환불 | 환불 신청 방법, 환불 기간, 주문 취소, 교환, 반품 배송비 |
| 상품 불량 | 파손·불량, 오배송, 구성품 누락, 포장 파손 |
| 기타 문의 | 상담원 연결, 회원 계정, 쿠폰·적립금, 영수증, 재입고 |

> ⚠️ 답변에 들어 있는 배송비, 무료배송 기준, 환불 기간, 전화번호(1234-5678), 운영시간은 **예시 값**입니다. 실제 서비스에 쓰려면 [intents.py](intents.py)에서 실제 정책에 맞게 바꿔 주세요.

## 동작 방식

```
질문 ─▶ 전처리 ─▶ TF-IDF 벡터 ─┬─▶ 분류 모델 ─▶ 카테고리별 확률 ─▶ 카테고리 결정
                               │
                               └─▶ 예시 문장과 유사도 비교 ─▶ 그 카테고리에서 가장 비슷한 세부 질문 ─▶ 답변
```

1. **전처리**: 물음표 같은 문장 부호와 "어떻게", "싶어요", "해주세요"처럼 어느 질문에나 나오는 말을 지웁니다. 이렇게 해야 핵심 단어로 비교할 수 있습니다.
2. **TF-IDF 벡터**: 문장을 글자 2~3개 단위로 잘라 숫자 벡터로 바꿉니다. 글자 단위로 비교하기 때문에 "배송돼요"와 "배송되나요"처럼 어미가 달라도 비슷한 문장으로 판단합니다.
3. **카테고리 결정**: 예시 문장으로 학습한 로지스틱 회귀 모델이 카테고리별 확률을 계산하고, 확률이 가장 높은 카테고리를 고릅니다.
4. **세부 질문 결정**: 고른 카테고리의 예시 문장 중 질문과 가장 비슷한(코사인 유사도) 문장을 찾아, 그 문장이 속한 세부 질문의 답변을 보여줍니다.
5. **이해 못함 처리**: 가장 비슷한 예시 문장의 유사도가 `0.3`(`THRESHOLD`)보다 낮으면 기본 안내 답변을 보여줍니다.

## 로컬에서 실행하기

Python 3.11에서 확인했습니다.

```bash
python3 -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

브라우저에서 http://localhost:8501 이 열립니다.
`intents.py`나 `test_data.py`를 고친 뒤에는 앱을 다시 켜지 않고 새로고침만 해도 반영됩니다.

## 질문·답변 추가하기

[intents.py](intents.py)에서 원하는 카테고리 안에 세부 질문을 추가합니다.

```python
"선물 포장": {
    "examples": ["선물 포장 되나요", "포장해서 보내주세요", "선물용으로 받고 싶어요"],
    "answer": "선물 포장은 결제 화면에서 선택할 수 있어요 (2,000원).",
},
```

- 예시 문장은 세부 질문마다 최소 3~5개 넣는 것을 권장합니다.
- 세부 질문끼리 예시 문장이 비슷하면 서로 헷갈리기 쉽습니다.
- 잘못 분류되는 질문이 있으면 맞는 세부 질문에 **비슷한 다른 표현**을 예시로 추가합니다.
- 새 카테고리를 추가하면 확률 막대와 엑셀 열도 자동으로 늘어납니다.

## 정확도 측정하기

앱의 **📊 정확도 테스트** 탭에서 [test_data.py](test_data.py)에 있는 문장 전체의 정확도를 볼 수 있습니다. 테스트 문장은 아래 형식으로 추가합니다.

```python
("주문하면 며칠 만에 받아요?", "배송", "배송 기간"),
("오늘 날씨 어때", None, None),   # 챗봇이 답하면 안 되는 질문
```

**현재 결과** (테스트 문장 41개)

| 항목 | 정확도 |
|---|---|
| 카테고리 | 95.1% (39/41) |
| 세부 질문 | 87.8% (36/41) |

> 틀린 테스트 문장을 그대로 `intents.py` 예시에 넣으면 정확도가 실제보다 높게 나옵니다. 테스트 문장과 학습 예시 문장은 따로 관리해 주세요.

## 배포

[Streamlit Community Cloud](https://share.streamlit.io)에 배포되어 있으며, GitHub `main` 브랜치에 push하면 자동으로 다시 배포됩니다.

```bash
git checkout -b 작업브랜치
# ... 수정 ...
git add . && git commit -m "수정 내용"
git checkout main
git merge 작업브랜치
git push origin main
```

- `requirements.txt`에 패키지를 추가하면 설치 때문에 반영까지 몇 분 걸립니다.
- 반영되지 않거나 오류가 나면 앱 오른쪽 아래 **Manage app**에서 로그를 확인하거나 **⋮ → Reboot app**을 누릅니다.
- 저장소가 공개(public)이므로 API 키 같은 비밀값은 코드에 넣지 말고 Streamlit의 **Settings → Secrets**에 넣습니다.

## 한계

- 글자가 얼마나 겹치는지로 비교하기 때문에, 같은 뜻이라도 쓰는 단어가 완전히 다르면 놓칠 수 있습니다.
- "점심 뭐 먹지"처럼 쇼핑몰과 상관없는 질문이 우연히 예시 문장과 글자가 겹치면 엉뚱한 답변이 나갈 수 있습니다.
- 대화 맥락을 기억하지 않아서, 질문 하나하나를 따로 분류합니다.
- 상담 기록은 브라우저 세션에만 남고, 새로고침하면 사라집니다. 필요하면 엑셀로 저장해 두세요.
